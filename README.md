# EGAT AssetCapture

เว็บแอป (PWA) สำหรับถ่ายรูปและบันทึกข้อมูลป้าย Nameplate อุปกรณ์ในสถานีไฟฟ้า ใช้งานได้แบบออฟไลน์

- **เปิดใช้งาน:** https://surawitsaisupun1994egat1-hub.github.io/egat-asset-capture/
- ติดตั้งเป็นแอป: Android กดปุ่ม "ติดตั้งแอป" ในหน้าตั้งค่า / iPhone แตะปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
- ข้อมูลและรูปถ่ายเก็บไว้ในเครื่องผู้ใช้เท่านั้น (IndexedDB) ไม่มีการส่งขึ้นเซิร์ฟเวอร์
- ส่งออกเป็น Excel / CSV / ZIP (รวมรูป) และสำรอง/กู้คืนเป็นไฟล์ .json
- `merge.html` คือหน้ารวมไฟล์จากหลายสถานี (สำหรับส่วนกลาง)

ที่เก็บนี้มีเฉพาะโค้ดของแอป ไม่มีข้อมูลอุปกรณ์ ข้อมูลส่วนบุคคล หรือเอกสารภายในใด ๆ
ไลบรารีที่ฝังในไฟล์: SheetJS, JSZip, ฟอนต์ Sarabun (OFL)
